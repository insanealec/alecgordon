# alecgordon

Personal website for Alec Gordon, live at [alecgordon.com](https://alecgordon.com).

Built with Vue 3, TypeScript, Vite, and Tailwind CSS. Homepage content lives in `src/data/profile.ts`.

## Deployment

Pushing to `main` builds and deploys to GitHub Pages.

## Project Setup

Requires Node 24 or newer.

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Type-Check, Compile and Minify for Production

```sh
npm run build
```

### Run Tests with [Vitest](https://vitest.dev/)

```sh
npm run test
```

### Lint with [ESLint](https://eslint.org/)

```sh
npm run lint
```
